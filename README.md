# Power Automate Training

Selbstgeführtes Power Automate Training für Bürokräfte und Power User – praxisnah, auf Deutsch, kostenlos.

📖 **Dokumentation:** [libsman.github.io/powerautomatetraining](https://libsman.github.io/powerautomatetraining)

---

## Lernpfade

| Lernpfad | Module | Thema |
|----------|--------|-------|
| LP 1 – Grundlagen | 0–5 | Interface, erster Flow, Konditionen, Schleifen, Expressions |
| LP 2 – M365 Integrationen | 6–12 | Outlook, Teams, SharePoint, OneDrive, Excel, Scheduled Flows |
| LP 3 – Business Flows | 13–19 | Genehmigungen, Fehlerbehandlung, HTTP, Szenarien |
| LP 4 – Desktop Flows | 20–24 | Power Automate Desktop, Web Recorder, UI Automation, RPA |
| LP 5 – Abschlussprojekte | 25–27 | Urlaubsgenehmigung, Reporting, IT-Ticketsystem |

## Lokale Vorschau

```bash
pip install -r requirements.txt
mkdocs serve
```

Dann im Browser öffnen: [http://127.0.0.1:8000](http://127.0.0.1:8000)

## Deployment

Die Dokumentation wird automatisch via GitHub Actions auf GitHub Pages deployed, sobald ein Push auf `main` erfolgt.
