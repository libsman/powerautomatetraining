# Power Automate Training

Willkommen! Dieses Training führt dich Schritt für Schritt durch **Microsoft Power Automate** – praxisnah, selbstgeführt und kostenlos.

Du arbeitest täglich mit Microsoft 365 und fragst dich, ob sich Routineaufgaben nicht automatisch erledigen lassen? Genau das ist Power Automate. Hier baust du echte Flows, automatisierst deinen Arbeitsalltag und lernst, wie du Zeit sparst ohne eine einzige Zeile Code schreiben zu müssen.

## Voraussetzungen

- Ein **Microsoft 365-Konto** mit Zugriff auf Teams, Outlook und SharePoint
- Ein Browser (Edge oder Chrome empfohlen)
- Für Lernpfad 4: Ein Windows-PC für Power Automate Desktop

!!! info "Keine Programmierkenntnisse nötig"
    Power Automate ist ein No-Code/Low-Code-Tool. Du klickst deine Flows zusammen, ohne eine einzige Zeile Code schreiben zu müssen. Expressions in Modul 4 sind optional – du kannst viele Flows auch komplett ohne sie bauen.
